日経マップ Gemini画像取込

バージョン 1.4.1
追加：PDF抽出ツールの「全記事の図解を順次生成・再開」から、画像用Gemini会話へ1記事ずつ送信し、完成画像を記事IDで取り込みます。生成APIは使いません。
元フォルダ：iCloud Drive/news1共通/gemini-map-import-extension
Chromeの拡張一覧で同名拡張を再読み込みし、PDF抽出ツール（v2026.10.10.4）も再読み込みしてください。
同時に新版の日経マップも公開してください。旧版マップは1.4.0を未対応として扱う場合があります。
登録済みのこのフォルダを更新した場合は、Chromeの拡張一覧で「日経マップ Gemini画像取込」の再読み込みボタンを押し、日経マップも再読み込みしてください。

初回設定（PCのChrome）
1. このフォルダを展開してください。
2. Chromeで chrome://extensions を開き、右上の「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択します。
4. 対応する新版の日経マップを公開してから、日経マップを再読み込みします。

普段の操作
1. Geminiで生成画像を表示し、会話URLをコピーします。
2. 日経マップの「このページの図解」→「URLから取り込む」にURLを貼ります。
3. 「URLを確認・取り込む」を押します。
4. プレビューと記事との対応を確認し、「対応を確認してサイトに保存」を押します。
画像のダウンロード・ファイル選択・クリップボードへの画像コピーは不要です。
Geminiの会話をまだ開いていない場合は、会話が開きます。画像を表示してから再試行します。

対象と制限
- PCのChrome用。Chromeスマートフォン版にはこの拡張は登録できません。
- Geminiで読み込み済みの生成画像のみ。1枚20MBまで。会話取込は30MB単位で分割します。
- 表示画像を取得します。フル解像度のダウンロード原本と同じとは限りません。
- 複数画像の並び順と離れた記事名を紐付けません。会話内のmanifest.jsonの候補記事・解説と、画像の本文・見出しを照合します。
- 1枚の取得に失敗しても取得済み画像を残し、失敗した枚数と理由を表示します。読み込み中の画像は再試行してください。
- 生成後の会話構造が変更された場合や取得元の制約により、取得できない場合があります。
- 日経マップのサイト保存には既存の公開キーが必要です。拡張にキーを入力する必要はありません。
- 取得だけでは公開しません。既存の保存操作を押した後でサイト閲覧者に公開されます。

アクセス範囲
https://gemini.google.com/ の指定会話で、生成画像、同じ応答内のファイル名、画像直後の解説、manifest.json内の記事候補・解説を読み取ります。
画像を要求できるサイトは https://nikkei-map.pages.dev/ と https://mitsu43.github.io/pdf-extractor-tool/ です。自動生成の開始は後者のみです。
自動生成は指定記事の短文プロンプトをGeminiへ送ります。応答上限や失敗時には停止します。画像をサイトへ公開するには、別途保存ボタンを押す必要があります。
拡張は会話全文、Cookie、パスワード、APIキーを送信しません。
生成API・生成API料金・外部中継サーバーは使用しません。
ソースは同封のmanifest.json / background.mjs / collector.mjs / map-bridge.jsで確認できます。
