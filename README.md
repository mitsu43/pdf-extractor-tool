# pdf-extractor-tool

## APIキー不要・5ページ手動連携

日経新聞PDFは `yyyymmddm.pdf`（朝刊）、`yyyymmdde.pdf`（夕刊）、`yyyymmddr.pdf`（地方版）、`yyyymmddp.pdf`（プラス1）の名前で読み込みます。

PDFを読み込むと、最大5ページ単位の処理枠を自動で準備します。APIキーは不要です。各枠で分割PDFをダウンロードし、「Geminiを開く」でコピー済みの指示文とPDFをGeminiへ渡してください。返答JSONを枠内へ貼り付けると、自動取込、必須項目検査、ページ番号補正、重複排除、連番振り直しを行います。全枠が合格すると、本番用JSONを自動保存します。

ブラウザの安全制限により、GeminiへのPDF添付と送信、Geminiからの回答コピーだけは人の操作が必要です。それ以外は画面内で自動処理します。

Gemini API自動モードも任意で利用できますが、標準はAPIキー不要の手動連携です。

## 記事の解説イラスト

抽出完了後、各記事の「解説イラスト」を押すと、記事内容を50歳前後の読者向けに図解する専用指示文をコピーしてGeminiを開きます。Geminiの入力欄へ貼り付けて送信してください。

図解には、記事の要点、生活・仕事・家計との関係、今後の注目点、専門用語1〜3語の日本語説明を含めるよう指示されます。
