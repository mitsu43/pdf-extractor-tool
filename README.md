# PDF全体抽出・図解の順次生成（v2026.10.10.3）

1. 「Gemini手動連携はPDF全体を1回で抽出」をONにして抽出する。JSONが途中までの場合は取り込んだ後「指示文コピー」を押し、同じGemini会話へ続行指示を送る。既出記事は保持される。
2. 日付・版を確認し「記事を確定」→「全記事の図解を順次生成・再開」を押す。
3. 拡張が画像用チャットを開き、「画像を作成」を選択して1記事ずつ送信。画像取得後に次へ進む。「停止」で次の送信を止め、同じ開始ボタンで再開できる。
4. 「記事・図解・説明を保存」を押す。日経マップを再読み込みする。

ZIP生成・画像生成APIは不要です。順次生成には「日経マップ Gemini画像取込」拡張1.4.0が必要です。既存登録フォルダはiCloud news1共通/gemini-map-import-extensionです。chrome://extensions の同名拡張の再読み込みを押して、抽出ツールも再読み込みしてください。権限・連携先は追加していません。

抽出ツールのタブを開いたまま実行してください。生成上限・拒否・ログイン切れ・4分のタイムアウトで停止します。制限の迂回や自動再送はしません。送信結果不明の場合はGeminiで確認が必要です。全記事が一度で生成できる保証はありません。

自動生成は送信ごとの固有IDと元記事IDを保持し、対応する応答だけから画像を取り込みます。OCRや画像の並び順では判断しません。Geminiが説明を返さない場合は、元記事データの説明を未照合と明記して表示します。公開前に確認してください。取得済み画像はIndexedDBに保存しますが、サイト共有は最後の「保存」が必要です。従来のURL・ファイル・ZIP取込も残しています。

保存先は既存の日経マップのR2です。既存のサイト保存キーを使用します。記事・画像・説明は1つの公開インデックスで反映し、他の日付・面のデータは残します。保存エラー時は取り込んだ内容を保持します。

マスターはiCloud news1共通/pdf-extractor-toolです。今回の変更前はnews1共通/バックアップ/20261010-sequentialに保持しています。
