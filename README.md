# PDF全体の図解生成・会話URL取込

1. PDFから記事JSONを抽出する。日付・版を確認して「記事を確定」を押す。
2. 「PDF全体をGeminiへ」を押す。全ページの指示をまとめてGeminiへ貼り付けて送信する。
3. 「Geminiの生成結果を取り込む」を押す。このツールから開いた生成タブを自動取得します。別の会話だけ任意のURL欄に指定します。
4. 「記事・図解・説明を保存」を押す。日経マップを再読み込みする。

ZIP生成・画像生成APIは不要です。Geminiの生成上限で停止した場合は、同じ会話で「続き」と指示します。一度での全件生成は保証できません。直接取込は既存のGemini画像取込拡張1.3.0が必要です。拡張と抽出ツールを再読み込みしてください。

会話内の画像ごとのコードブロックと記事ID・正式タイトルを照合します。選択順では紐付けません。説明がなければ保存ボタンは無効です。画像ファイルの選択と従来ZIP取込も残しています。

保存先は既存の日経マップのR2です。既存のサイト保存キーを使用します。記事・画像・説明は1つの公開インデックスで反映し、他の日付・面のデータは残します。保存エラー時は取り込んだ内容を保持します。

マスターはiCloud news1共通/pdf-extractor-toolです。旧版はnews1共通/バックアップ/20261010-extractor-bundleに保持しています。
