# 記事・4コマ・説明の同時保存

1. PDFから記事JSONを抽出する。日付・版を確認して「記事を確定」を押す。
2. 紙面を選び「この面をGeminiへ」を押す。コピーした指示をGeminiへ貼り付けて送信する。
3. Geminiから受け取ったZIPを「ZIP・画像を取り込む」で選ぶ。
4. 「記事・図解・説明を保存」を押す。日経マップを再読み込みする。

Geminiの会話URLを指定すると、次の面も同じ会話へ渡せます。生成APIは使用しません。生成・ZIP化はGemini側で対応できる場合に限られます。

ZIPは実画像とmanifest.jsonが必要です。各itemsにはgid、title、article_number、filename、explanationを含めます。ID・タイトル・日付・版・面の不一致は取り込みません。選択順では紐付けません。説明がなければ保存ボタンは無効です。

保存先は既存の日経マップのR2です。既存のサイト保存キーを使用します。記事・画像・説明は1つの公開インデックスで反映し、他の日付・面のデータは残します。保存エラー時は取り込んだ内容を保持します。

マスターはiCloud news1共通/pdf-extractor-toolです。旧版はnews1共通/バックアップ/20261010-extractor-bundleに保持しています。
