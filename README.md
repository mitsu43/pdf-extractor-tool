# pdf-extractor-tool

## APIキー不要・5ページ手動連携

日経新聞PDFは `yyyymmddm.pdf`（朝刊）、`yyyymmdde.pdf`（夕刊）、`yyyymmddr.pdf`（地方版）、`yyyymmddp.pdf`（プラス1）の名前で読み込みます。

PDFを読み込むと、最大5ページ単位の処理枠を自動で準備します。APIキーは不要です。各枠で分割PDFをダウンロードし、「Geminiを開く」でコピー済みの指示文とPDFをGeminiへ渡してください。返答JSONを枠内へ貼り付けると、自動取込、必須項目検査、ページ番号補正、重複排除、連番振り直しを行います。全枠が合格すると、本番用JSONを自動保存します。

ブラウザの安全制限により、GeminiへのPDF添付と送信、Geminiからの回答コピーだけは人の操作が必要です。それ以外は画面内で自動処理します。

Gemini API自動モードも任意で利用できますが、標準はAPIキー不要の手動連携です。

## Chrome拡張機能

`chrome-extension` フォルダをChromeの「拡張機能を管理」から「パッケージ化されていない拡張機能を読み込む」で指定すると、「Geminiへ自動入力」が使えます。バッチ数分のGeminiタブを開き、それぞれへ対応する指示文を入力します。誤送信防止のため送信ボタンは自動で押しません。

「分割PDF一括」は、最大5ページごとのPDFを順番にダウンロードします。初回にChromeが複数ファイルのダウンロード許可を求めた場合は許可してください。

## 記事の解説イラスト

抽出完了後、各記事の「解説イラスト」を押すと、中学生でも段階を追って理解できる学習マンガ図解の専用指示文をコピーしてGeminiを開きます。Geminiの入力欄へ貼り付けて送信してください。

図解には「何が起きたか」「専門用語」「原因から結果まで」「立場別の影響」「間違えやすい点」「理解度チェック」を含めます。記事にない数字や発言を作らず、事実・見解・説明用の例を区別する指示も含みます。

## 図解の一括反映

抽出結果の下にある「記事図解 一括反映」を使います。

1. 日付と版を確認して「図解一覧を作成」を押す。
2. 「全記事をまとめてGemini生成」で、全記事分の日本語図解指示を1回でコピーしてGeminiを開く。画像内の英語・ローマ字・架空文字は禁止する指示を含みます。
3. 生成画像をまとめて選択またはドロップする。
4. 画像と記事の対応表を確認する。`001-円安.png`のように記事番号から始まるファイル名は自動対応する。
5. Cloudflare公開キーを入力し、「Cloudflareへ一括反映」を1回押す。

記事JSONと図解画像は別に保存されます。図解の追加で記事本文、地図、読み上げデータは上書きしません。公開キーはブラウザの端末内だけに保存し、HTMLやGitHubには書き込みません。

## 図解の日本語と保存名

v2026.10.06.3では個別・一括とも、日本語原稿の確定、校正、描画、原稿との照合の順に作る指示に変更しました。保存名は本文から分離した管理データに置き、画像内への描画を禁止しています。画像の対応付けに使うファイル名の形式は変えていません。

これは生成指示の改善であり、ツールによる自動校正・文字組版の実装ではありません。生成画像の日本語を完全には保証できません。既存の画像は変更せず、新しくコピーした指示文から適用されます。
